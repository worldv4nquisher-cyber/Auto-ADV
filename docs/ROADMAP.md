# Auto-ADV 路线图（v0.3）

> 架构细节见 [ARCHITECTURE.md](./ARCHITECTURE.md)。

## 排期原则

1. **每个阶段结束都有一个能实际玩的东西。**
2. **先文本，后多媒体。** 文本是一切的地基，图、音、视频都是增强层。
3. **"Auto" 尽早出现。** 观察模式是核心卖点，排在第二个可玩阶段，而不是最后。
4. 不写时间估计：先做完 M0 / M1，用真实速度再估后面的。

## M0 骨架 ✅

> 已完成：见下方清单。附带一个模拟 OpenAI 兼容服务（`pnpm cli mock-server`），没有 API Key 也能开发调试；CI 在 Windows 上自动打安装包并跑端到端测试。

- 开发与打包以 **Windows** 为首要目标（路径处理、原生模块 better-sqlite3 的预编译、密钥加密都先在 Windows 上验证）
- pnpm monorepo、Electron 应用壳、引擎进程（utilityProcess）、界面与引擎之间的类型安全 RPC
- 文本模型适配器：**OpenAI 兼容**（同时覆盖 DeepSeek、通义千问、Kimi、OpenRouter、Ollama、LM Studio 等）；"测试连接"按钮 + 能力探测（结构化输出、工具调用、流式用量）
- 设置页：模型配置、职责路由、API Key 加密存储
- 调用日志面板：每次调用的提示词、输出、token、费用
- 原生格式 schema v0

**验收**：在设置里配好模型，能在调试面板发一条消息，看到流式回复和本次花费。

## M1 首个可玩版：文本创世 + 自由对话 ✅

> 已完成。具体做法见 [ARCHITECTURE.md 第 14 节](./ARCHITECTURE.md#14-m1-实现备注)。另外加了 `pnpm cli genesis "灵感"`：不开界面跑一遍创世，方便用真实模型调提示词。
> 推迟到后面的：世界内容的手动编辑（M5 编辑器）；创世时的"锁定"（M5）。

- 一键创世（文本部分）：简报 → 世界观 → 角色 / 地点 → 设定集 / 开场；中断或失败可续跑，任意一步可以重抽
- 世界文件夹读写；启动器（世界列表，像 Minecraft 的"单人游戏"页）
- 自由对话：单角色 + 群聊，设定集关键词触发
- 事件日志 + 分支树：重抽、编辑、回退、存档读档
- 基础记忆：场景摘要（滚动的前情提要）

**验收**：输入一句话，几分钟内得到一个世界并开始和角色聊天；能重抽、回退、存档读档。

## M2 观察模式（Auto 核心）✅

> 已完成。具体做法见 [ARCHITECTURE.md 第 15 节](./ARCHITECTURE.md#15-m2-实现备注)。命令行 `pnpm cli observe` 可以无人值守跑 N 拍并打印质量报告（`--mock` 不需要 API Key）。
> 2026-11-22 用真实模型（MiniMax-M3.1-Flash）短测 25 拍通过，结果和发现的问题见 ARCHITECTURE.md 第 15 节末尾。一小时长测（`pnpm cli observe --beats 100 ...`）留到正式版发布前再做。
> 推迟到后面的：观察模式的 VN 舞台呈现（M3，已完成）；"倍速"目前是阅读速度，生成速度由预生成缓冲和每分钟上限控制。

- 导演 / 演员 / 旁白 / 书记；合并模式与分演模式
- 结构化动作 + 引擎裁决
- 剧情骨架生成，导演按骨架推进；信息不对称（角色私有记忆）
- 持续运行：预生成缓冲、暂停 / 倍速、导演指令、悄悄话、接管角色
- 防崩坏：重复 / 停滞检测、事件卡池
- 预算上限与安全阀
- 命令行工具：无人值守跑 N 拍并输出质量报告

**验收**：新建世界选观察模式，放着不管跑一小时，故事持续推进、不明显重复、不超预算。

## M3 剧情 ADV 模式

> 设计见 [ARCHITECTURE.md 第 16 节](./ARCHITECTURE.md#16-m3-设计剧情-adv-模式)。先做简单版：先用手写剧本在命令行和舞台上跑通，再接 AI 生成。
> 第 1 步已完成（剧情图、条件、结构检查、进度折叠、数值上限和检定、跨周目进度、旧骨架迁移、`.adv` 剧本）：`pnpm cli check-plot` / `pnpm cli adv` 可以在命令行把示例世界 `examples/worlds/old_library` 玩到 4 个结局。具体做法见 [ARCHITECTURE.md 第 17 节](./ARCHITECTURE.md#17-m3-实现备注)。
> 第 2 步已完成（VN 舞台：背景、立绘站位、文本框、回想、自动播放、快进、存读档，素材用占位图）：在应用首页「导入世界」选示例世界，开始「剧情 ADV」周目就能玩到结局。
> 第 3 步已完成（接 AI）：创世生成剧情图和数值，结构检查不过就让模型重写；观察模式的导演按幕推进，走到结局后续写新的篇章；剧情 ADV 里没有手写剧本的幕由 AI 演出，每一拍给玩家选项（可以带检定），也可以直接输入想做的事，岔路只由玩家决定。还没做：ADV 跑偏时的四个选项、出口上的检定、ADV 里重抽一拍。
> 第 4 步已完成：观察模式默认在同一个 VN 舞台上自动播放（背景、立绘、标题卡、检定、回想），也可以切回文本看法做重抽、改写、分支。
> 收尾：ADV 跑偏时的四个选项（拉回来 / 就这样走 / 暂停剧情图 / 不用管）和世界页的「收集」（结局、CG 画廊、走过的幕）已完成，见 [ARCHITECTURE.md 17.5](./ARCHITECTURE.md#175-m3-收尾adv-跑偏的四个选项收集页)。2026-11-24 用真实模型（MiniMax-M3.1-Flash）短测了剧情图生成、ADV 的 AI 演出和跑偏时的"就这样走"，修了跑偏提问不触发等 4 个问题，见 [ARCHITECTURE.md 17.6](./ARCHITECTURE.md#176-真实模型短测剧情图和剧情-adv)。出口上的检定、ADV 里重抽一拍还没做。

- 剧情图：用"幕 + 出口"代替篇章 / 章节 / 节拍骨架，由引擎按出口和条件判断换幕；三种模式共用；旧世界自动迁移
- 结构化的出口 / 结局条件（不用字符串表达式），开玩前做结构检查（`pnpm cli check-plot`）
- 数值与检定：模型提出的数值变化每拍有上限；骰子由引擎掷，结果跟剧情位置绑定，重抽换不了
- Script IR + 手写剧本的文本格式
- VN 舞台：背景、立绘站位、文本框、回想、自动播放、快进、存读档界面
- 选项与分支：岔路只由玩家决定；ADV 模式跑偏时给玩家四个选择（拉回来 / 就这样走 / 暂停 / 不用管）
- 结局与 CG 回收界面：跨周目进度单独存，不随回退和分支撤销
- 观察模式也切换到 VN 舞台呈现（跑偏时由导演自己拉回，不弹选项）

**验收**：一个带选项和数值的完整章节能玩通，并能达成不同结局（素材先用占位图）；手写剧本和 AI 生成的剧情图都能通过结构检查。

## M4 素材管线

- 任务队列、缓存、进度显示
- 图像：OpenAI 图像接口 + ComfyUI；背景、立绘（定妆照 + 表情差分）、透明背景、CG
- 立绘依赖图：角色设定板 → 服装设定板 → 基础立绘 → 表情差分，上游重画后下游自动标"过期"，和创世管线共用一套机制（[ARCHITECTURE.md 8.2](./ARCHITECTURE.md#82-立绘一致性最难的部分)）
- BGM：情绪曲目生成或从曲库挑选，按场景情绪自动切换、淡入淡出
- 音效、TTS 语音
- 通用 HTTP 适配器

**验收**：新建世界自动带上背景、立绘和 BGM，开场五分钟内素材到位。

## M5 完整创世器与编辑器

- Minecraft 式"更多世界选项"，覆盖每一个生成步骤
- 向导模式（每阶段审阅、修改、重抽）
- 锁定 / 重抽 / 下游过期
- 世界编辑器：角色、设定集、剧情骨架、素材
- 题材与风格预设、成本预估
- `.advworld` 导出导入

## M6 同人模式 + 外部兼容

- 文本导入、分块抽取、原作标注、分歧点选择
- 文风学习
- SillyTavern 角色卡 / 世界书导入导出

## M7 打磨与扩展

- 视频：片头、章节过场、结局
- PixiJS 舞台、转场特效、Live2D
- 离屏世界模拟：不在场的角色也在过自己的生活
- 插件系统（适配器、生成步骤、剧本指令、界面主题）
- Anthropic、Gemini 原生接口适配器
- Windows 安装包签名、自动更新；之后再做 macOS / Linux

## 已确认

- 技术栈：Electron + TypeScript
- 首发平台：Windows
- 优先模型接口：OpenAI 兼容格式

## 待讨论的问题（都不阻塞 M0）

1. **本地显卡**：有没有本地显卡跑 ComfyUI / Ollama？决定 M4 素材管线先做云端还是本地。
2. **内容分级**：完全交给用户设置，还是有默认限制？
3. **语言**：生成内容和界面都中文优先，需要英文吗？
4. **仓库**：公开还是私有？开源的话用什么协议？
5. **观察模式默认形态**：AI 扮演主角，还是没有主角的群像剧？（两种都会支持，问的是默认值）
