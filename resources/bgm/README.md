# 内置曲库

随应用一起发的一小套公有领域钢琴曲（ARCHITECTURE.md 18.7）。什么都没配（没有本地曲库，也没有音乐模型）时，舞台用这里的曲子。

现在的 12 首每个情绪两首，都是用 `scripts/bgm/build.py` 从 Mutopia 上标为公有领域的 LilyPond 乐谱渲染的，做法见 `scripts/bgm/README.md`。曲目和授权在 `manifest.json` 里，应用的「设置 → 关于」也会列出来。

## 放进来的规矩

作曲家去世早，作品本身是公有领域，但录音和乐谱的现代编订版可能有自己的版权。所以每个文件只能是下面两种之一：

1. 用公有领域（或 CC0）的乐谱，配一个允许再分发的钢琴音色库自己渲染出来；
2. 录音本身明确放进了公有领域（CC0 或公有领域标记），逐个文件核对过。

每首都要在 `manifest.json` 里写一条，应用的「关于」页按它列出授权：

```json
{
  "tracks": [
    {
      "file": "satie-gymnopedie-1.ogg",
      "title": "Gymnopédie No.1",
      "composer": "萨蒂",
      "mood": "daily",
      "source": "乐谱的来源链接",
      "method": "怎么做出来的：用哪个音色库渲染，或者是谁的录音",
      "license": "作品：公有领域；乐谱：……；音色库：……"
    }
  ]
}
```

- `file` 只能用字母、数字、点、横线和下划线，文件放在这个文件夹里；
- `mood` 是默认情绪表里的 id：`theme`、`daily`、`tense`、`sad`、`warm`、`climax`；
- 压成 64～96 kbps 的 Ogg/Opus（现在的曲子是 64 kbps）。同一情绪放两三首，舞台按顺序轮着放（不循环，放完淡出、停几秒再放下一首）。

清单里写了、文件不在的曲目会被忽略。
